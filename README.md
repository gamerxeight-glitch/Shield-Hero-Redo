# Shield-Hero-Redo — Canon Source Compendium

A structured, **paraphrased** reference for *The Rising of the Shield Hero*
(盾の勇者の成り上がり, by Aneko Yusagi), assembled as the foundation for rebuilding
the world into a script-based roleplay bot.

## What this is
A clean, organized canon reference covering the cast, world systems, the Waves,
the nations, and the arc-by-arc timeline across the anime / manga / light novel
continuity. It is the **raw material** we'll later shape into the bot (character
card, lorebook scripts, master engine).

## Compliance note
Everything here is written **in our own words** — paraphrased factual summaries,
not copied text. No light-novel/manga prose is reproduced verbatim. Where a fact
came from a reference, the source is cited. Content was rephrased for compliance
with licensing restrictions.

## Sources
- Wikipedia: *List of The Rising of the Shield Hero characters*; *List of volumes*; main series article.
- The Rising of the Shield Hero Wiki (shield-hero.fandom.com): Waves of Calamity, Guardian Beasts, Four Legendary Weapons, Vassal Weapons, Dragon Hourglass, Status Magic System, Curse Series, Melromarc, Siltvelt, Zeltoble, Q'ten Lo, World Map.

## Continuity caveat
The web novel, light novel, manga, and anime diverge (notably the LN expands and
then splits from the web novel around volumes 8–9, fully by ~vol 16). Where they
differ in a way that matters, the file flags it. Treat this as a *canon baseline*
we can deviate from deliberately when we "redo" the world.
