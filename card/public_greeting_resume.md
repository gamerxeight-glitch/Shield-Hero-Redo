# Public Greeting D — Resume / Freeform Save-Load

> Paste into Janitor's **Alternate Greeting** slot (the 4th greeting). This is
> NOT a scripted scene like Greetings A/B/C — it's a save-load utility that lets
> a user resume a previous chat past a context reset, and optionally go fully
> freeform from that point on.

---

## HOW TO USE (share this part with end users, e.g. in the bot's description)

1. In your **old** chat, copy your **last message in full** — it ends with the
   hidden `~~~SV...~~~` checkpoint (time / EP / reputation / party state). If
   you don't see it, scroll to the very end of the message; it's wrapped in
   `~~~` so it renders invisibly, but it's still there in the raw text.
2. If you have a memory/summary block (recent beats, relationships, open
   threads), copy that too — paste it directly beneath the checkpoint text.
3. Start a **new chat**, select this **Alternate Greeting**, and **replace the
   single "." below** with everything you just copied. Leave the OOC line at
   the bottom exactly as it is — it tells the engine and the model this is a
   freeform continuation, not a fresh EP1 start.
4. Send. On your first real turn, the engine reads the checkpoint and resumes
   EP / time / reputation / party exactly where you left off — no manual setup.

## SCOPE OF THE OOC — read before editing this file

The OOC line lifts **plot/canon gating only** — from this point on, {{user}} is
free to diverge from the scripted episode arc, skip ahead, or go fully
off-script. It does **NOT** lift the hard rules. Everyone remains an adult
(18+) and {{user}} is never authored — those hold unconditionally, with or
without this greeting. Do not reword this OOC into a blanket "all restrictions
lifted" — that reads as a safety bypass, breaks the hard rules, and risks the
bot being taken down.
